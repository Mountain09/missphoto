現場排除手冊

機台在活動現場出狀況時，先照這裡一步一步檢查。照片都是從教育訓練影片截下來的，點圖片可以放大。

拍攝引導流程帶客人拍一輪的標準步驟和要講的話

現在發生什麼事？

印不出來沒反應、印表機離線、印出來顏色怪 客人要補印、加洗找回剛剛拍的照片，再印一張或多張 閃光燈沒閃照片很暗、燈沒跟著閃，或被別台閃到 相機沒畫面、顏色怪偏黃偏藍、太亮太暗、模糊、螢幕黑的 軟體設定預覽太暗、透明相紙、午晚宴分場
標準流程

拍攝引導流程

從選相框到列印，帶客人拍一輪的標準順序。

  1. 介紹相框，請客人選一款（客製相框先確認要拍幾張）

  2. 請客人站集中、頭靠在一起，整群往前半步

  3. 眼睛看機台上方的黑色鏡頭

  4. 倒數三、二、一，每張換一個姿勢

  5. 拍完請客人往前一步一起檢查，不 OK 就重拍

  6. 若當天有開濾鏡，問客人要印彩色或黑白，確認張數後列印

印表機

印不出來、印出來顏色怪

先看印表機本身，再看電腦。印得出來但顏色不對，多半是 ICM 沒設好，直接看第 5 步。

先檢查這 3 件事

  • 印表機有開機，面板沒有亮紅燈或錯誤訊息
  • 相紙和色帶還有、有裝好，沒有卡紙
  • 印表機到電腦的 USB 線沒有鬆掉

  1. 確認電腦有抓到印表機

    開始 → 設定 → 藍牙與裝置 → 印表機與掃描器（或從控制台 → 硬體和音效 → 裝置和印表機）。清單裡要看得到 DS-RX1，狀態不能是「離線」或「錯誤」。

  2. 按「列印測試頁」

    點進 DS-RX1，按「列印測試頁」。

    • 印表機有動：印表機沒問題，回頭檢查是不是選錯印表機，或看第 6 步的軟體型號。
    • 印表機沒動：代表有問題。檢查連線、USB 線，還有是不是選錯印表機。清單裡有時候不只一台 RX，要確認點的是對的那台。

  3. 還是不行：移除印表機

    打開控制台 → 硬體和音效 → 裝置和印表機，找到 DS-RX1，按右鍵（或長按）選「移除裝置」。

  4. 電腦和印表機都重新開機

    兩邊都重開後，電腦會自動重新抓印表機的驅動，DS-RX1 會再出現在清單裡。出現後試印一張看看有沒有連上。

  5. 把色彩設定改成 ICM

    重新抓到的印表機設定會回到預設值，一定要重設。點 DS-RX1 →「列印喜好設定」→ Option 分頁，色彩調整預設在 None，改選 ICM，按「套用」。

    沒改成 ICM，印出來的顏色會不對。平常印出來顏色怪，也先檢查這一項。

  6. 確認軟體裡的印表機型號

    Missphoto 的「列表機型號」要選 DNP Rx1，選錯會印不出來。做法看 軟體設定。

最後手段：重新安裝印表機驅動

上面都試過還是不行，才需要重裝驅動。機台用的印表機有 DS-RX1 和 DS620 兩種，先確認是哪一台。

  1. 到經銷商網站下載驅動

    用 Chrome 搜尋「宗橋企業」，點進 p-bridge.com.tw 的網站。

    在網站裡找「下載服務」，下載對應機型的驅動：RX1 選 DS-RX1_Driver_for_Windows_11，620 選 DP-DS620_Driver_windows11。

  2. 移除舊的驅動

    控制台 → 程式集 → 解除安裝程式。往下找一串很長的「Windows 驅動程式封裝…」，後面會寫 DS620 或 DS-RX1，把對應的那個移除。

  3. 安裝新的驅動

    把剛剛下載的檔案解壓縮，執行安裝。

  4. 試印，並設定 ICM

    裝好後印一張測試，記得照上面第 5 步把色彩設定改成 ICM，不然顏色會不對。

照片檔案

客人要補印、加洗

每張拍好的照片都會自動存在電腦裡，可以找出來再印，也能一次印好幾張。

  1. 叫出 Windows 畫面

    這台是從螢幕最下方往上滑，Windows 的工作列就會跳出來。有些機台下面滑不出來，就改從左邊往右滑。

    小技巧：開兩個視窗，一個是拍貼程式，另一個用來開資料夾、處理後台，切換比較方便。

  2. 打開照片資料夾

    開啟檔案總管 → 本機磁碟 (C:) → Missphoto → Card。拍完的照片都會自動存在這裡。

  3. 找當天日期的資料夾

    資料夾用日期命名，例如 7 月 26 日就是 20260726。同一天有午宴和晚宴時，如果晚宴有把活動場次改成 2，兩場照片會自動分開；沒改的話就都在同一個資料夾，依拍攝時間排列。

  4. 長按照片 → 顯示其他選項 → 列印

    確定是客人要加洗的那張，長按它，選「顯示其他選項」，裡面就有「列印」。

  5. 確認印表機，取消「相片適合框架」

    印表機要選 DS-RX1。清單裡有時會出現 RX 的複本 1、2、3，選錯會印不出來。

    下方「相片適合框架」（也就是填滿）的勾要拿掉。要加洗多張，就在這裡調整份數，例如改成 4。

  6. 按「選項」，設定裁切

    點右下角「選項」→ 印表機內容 → 進階，最後一項 2inch cut 依相框格式設定：

    相框格式2inch cut結果
    4×3 等一般格式Disable不裁切，印出來後人工裁切
    書籤格式Enable印表機直接切開

    印表機只能切書籤格式，4×3 沒辦法自動切。

  7. 按「列印」

    設定好就按「列印」，照片會直接洗出來。

閃光燈

閃光燈沒閃、被別台閃到

觸發器和燈頭要設在同一個群組（Group）才會閃。現場有其他機台或閃燈時，要各自用不同群組，才不會互相觸發。

先檢查這 3 件事

  • 閃光燈插頭有插好、燈頭電源有開
  • 觸發器有插在相機上方的熱靴，而且有開機（亮綠燈）
  • 觸發器和燈頭的群組一樣

  1. 看觸發器的群組

    觸發器開機後會亮綠燈。上面那排要對，下面那排沒差。

  2. 燈頭：上、下鍵一起按，進入設定

    在燈頭背面同時按上、下兩個鍵，螢幕會開始閃，代表進入設定。再按旁邊的按鍵，把群組改成跟觸發器一樣，例如從 G 改成 G2。

  3. 按測試鈕試閃

    群組一樣，按了燈就會閃；群組不一樣就不會閃。有閃就代表設好了，再回到機台拍一張確認。

  4. 附近有兩台以上：各設不同群組

    同一個場地有好幾台機台或其他閃燈時，有時候會被別台閃到。每一台的觸發器和燈頭都設一組自己的群組，例如這台 G1、隔壁 G2。

相機

相機沒畫面、照片顏色怪或模糊

相機設定被動到，照片就會太亮、太暗或偏色。裝好相機後先照下面的表檢查一次，有跑掉的就改回來。

項目標準值備註
拍攝模式M相機上方轉盤
快門1/125轉上方滾輪；數值也會公告在群組
光圈F6.3長按 Av 鍵再轉滾輪
ISO400由軟體控制，現場不用調
相片風格人像 7・0・0・0銳利度 7，其他歸零
白平衡AWB 自動偏藍時改日光或陰天
白平衡偏移0 / ±0當場有指示才調

  1. 沒畫面：按即時顯示鍵

    相機接上後螢幕沒畫面，按觀景窗右邊的即時顯示鍵，畫面就會出來。

  2. 確認 M 檔、125、6.3

    轉盤在 M，螢幕下方要是快門 125、光圈 6.3。ISO 由程式控制，不用自己調，通常是 400。

    數值跑掉時：觸控機型直接點螢幕下方的數字調整。不是觸控的，直接轉相機上方的滾輪是調快門；長按 Av 鍵不放再轉滾輪是調光圈，放開就回到快門。

    數值調大照片
    快門（125 → 160）變暗
    光圈（6.3 → 8）變暗
    ISO（400 → 800）變亮

  3. 相片風格：人像，7・0・0・0

    按 MENU → 紅色拍攝選單 →「相片風格」，選人像。要改細項就照螢幕下方提示的按鍵進去，把第一項（銳利度）調到 7，其他都歸零，再按 MENU 回去。有些機型是觸控螢幕，可以直接點。

    除非當天有特別交代用別的設定（例如自動），不然一律用人像 7・0・0・0。

  4. 白平衡：通常用 AWB

    按 Q 鍵，選白平衡，平常用 AWB（自動）。如果那一場拍出來或印出來偏藍，就改成日光或陰天，或照當天的指示改。

  5. 白平衡偏移：平常歸零，有指示才調

    MENU →「白平衡偏移/包圍」。平常方格中間的點要在正中央（0 / ±0）。每場燈光不一定，如果有人交代「藍加 1」或「綠加 1」，就用方向鍵往那個方向移，再按 SET。

  6. 照片模糊：重新對焦

    鏡頭左側有 AF / MF 開關。先切到 AF，請一個人站在客人拍照的位置，相機朝前方輕按快門（半按）對焦，等對焦點的綠點都出來後按下快門，再把開關切回 MF。這樣這段距離的焦就固定好了。

相機顯示「相機中沒有記憶卡」是正常的。照片會直接傳到電腦，不用插卡。

螢幕上正常、印出來才怪？那是印表機的問題，看 印表機的 ICM 設定。

Missphoto 軟體

軟體設定跑掉

螢幕預覽太暗、印表機型號、午晚宴分場，都在 Missphoto 的控制台改。

  1. 打開軟體的控制台

    軟體開著時是「點擊螢幕任意地方」的畫面，設定都在 Missphoto 的控制台裡。時間、重拍次數、列印張數這些欄位照字面意思就懂，現場最常調的是預覽 ISO。

  2. 螢幕預覽太暗或太亮：調預覽 ISO

    預覽 ISO 只控制螢幕上看到的預覽畫面，數字越大越亮、越小越暗。只能選 2 的倍數：200、400、800、1600、3200、6400，選 5000 這種數字沒有作用。通常從 3200 開始，不夠亮再調 6400。

    選好後按旁邊的「設置」，右邊的數字有跟著變，就代表調好了。

    拍照 ISO 固定 400，不要改。它跟預覽 ISO 在同一個地方，別調錯。

  3. 選對印表機型號

    「列表機型號」平常選 DNP Rx1，按「套用」。

    用透明相紙時要改成 DNP DS620。透明相紙用的是 620 印表機，型號還設 Rx1 的話沒辦法裁切。這種情況比較少，但偶爾會遇到。

  4. 午宴、晚宴分開：改活動場次

    同一天做午宴和晚宴時，午宴的「活動場次」用 1，到晚宴改成 2，按「設置」，右邊「現在場次」變成 2 就好了。兩場的照片會自動分開存，不用手動整理。

    機台辨識碼不用改。照班表上的代號（例如 M1），午晚宴都一樣，靠場次來分。
